# 拟剧论 · 每个人都有后台

Remotion 知识短片：1920×1080、30fps、165 秒（4950 帧），中英双语字幕，无配音。
从“世界是个巨大的草台班子”切入：会上点头、装得什么都会、对镜子练台词；
再讲戈夫曼的前台与后台、剧班；为什么总觉得只有自己在装；演也是体面；最后“给自己留一个后台”。

## 运行

```bash
npm install
npm run render                                     # 输出 out/drama.mp4
npx remotion still Cover out/cover.jpg --frame=0   # 竖版封面 1080×1440
node stills.mjs 600 1200                           # 渲染指定帧到 out/f<帧>.jpg
```

音乐 `public/audio/bgm_A_hell_no_vocals.wav` 未入库，与另外几部同一条，生成步骤见 `../theseus-ship/audio/README.md`。

## 依据

- 戈夫曼曾在设得兰群岛的一个小岛上住了一年做博士论文的田野调查；《日常生活中的自我呈现》提出前台/后台、剧班。
- 餐厅服务员在前台得体、在后台一起吐槽客人，是对他理论的常见说明；片中没有声称这是小岛上某家旅馆的具体记录。
- “演的人常常自己也信了”对应书中“完全被自己的表演所说服”的真诚表演者。
